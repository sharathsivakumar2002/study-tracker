# Study Session Tracker

A productivity-focused study tracker built using JavaScript that helps students monitor study sessions, subjects, and learning consistency.

## 🚀 Features
- Start / Stop study timer
- Track subject and topic
- Save sessions using LocalStorage
- Persistent study history
- Dynamic UI updates

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 📚 Concepts Used
- DOM Manipulation
- LocalStorage
- setInterval
- Event Handling
- Arrays & Objects
- Date API

## ▶️ How to Run
Open `index.html` in browser.
